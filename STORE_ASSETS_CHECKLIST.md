# Play Store Assets Checklist

## Required Assets

### App Icon
- [ ] 512×512 PNG
- [ ] No alpha/transparency
- [ ] Background color: #F7F6F3
- [ ] Foreground: LifeTrack Pro logo
- Tool: Canva (free) or Figma

### Feature Graphic
- [ ] 1024×500 PNG
- [ ] Shows app value proposition
- [ ] Text: "Your Life. One App."
- [ ] Background: #17172A (navy)

### Phone Screenshots (minimum 4)
- [ ] Size: 1080×1920 or 1080×2400
- [ ] Screenshot 1: Home Dashboard
- [ ] Screenshot 2: Focus Mode (dark)
- [ ] Screenshot 3: Goal Vault
- [ ] Screenshot 4: Stats/Heatmap
- Tool: Take on real device, or use Figma device mockup
